# Building a Radiographic Diagnostic System using CLIP and LLM

## Overview
This project presents an AI-based system for chest X-ray classification using CLIP feature extraction and a lightweight neural network classifier.

## Methodology
- Feature extraction using pretrained CLIP (ViT-B/32)
- Fully connected neural classifier
- Evaluation using accuracy, confusion matrix, and ROC curve

## Results
- Training Accuracy: ~99%
- Validation Accuracy: ~97%
- Test Accuracy: ~85%

## Repository Structure
- `model/` trained model
- `notebooks/` training and evaluation code
- `results/` plots and evaluation figures
- `report/` written analysis

## Note
The notebook is executable end-to-end.
